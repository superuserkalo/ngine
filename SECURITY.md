# Security

## What ngine can access

A screen recorder sees whatever is on the screen and can hear whatever the
selected audio sources carry. ngine asks the operating system for those
permissions and writes recordings to local files.

## Reporting a vulnerability

Please report security problems privately through GitHub's "Report a
vulnerability" button on the repository's Security tab. Do not open a public
issue for something exploitable.

Include your operating system, the version or commit, and the smallest steps
that reproduce the problem. Leave out recordings or screenshots that show
personal content.
